# Homepage Figure Sources

This folder stores the editable vector source documents for figures embedded in
the homepage.

- `fig-wam-definition.html` wraps the tracked SVG source at
  `../../img/figures/fig-wam-definition.svg` for consistent vector embedding.
- `fig-wam-timeline.html` is the editable HTML/SVG source copied from the active
  survey figure source and served directly by the homepage.
- `generate_wam_timeline.py` regenerates `fig-wam-timeline.html` from its
  embedded timeline data.
- `style.css` provides local fonts and responsive figure-document sizing.
